💡 三个关键概念

① 一切皆插件
连 Agent 主循环、会话日志都是插件。想换任何部分 → 挂新插件覆盖，无需改内核。
② 分层叠加（patch）
配置像千层饼：bundles → profile patch → home patch → --patch。上层覆盖下层。
③ 能力 Seam
接口 + 实现分离。换实现（如远程沙箱）→ 整个产品的这个能力跟着变。

🔁 轮次流程

你发消息 → 会话记录
→ 组装提示词（含工具 schema）
→ 请求模型 → 回话 / 调工具
→ 工具执行（过审批/沙箱）
→ 结果写回日志 → 继续
→ 直到轮次结束
