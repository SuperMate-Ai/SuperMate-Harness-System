# 功能与说明（FEATURES）

本仓库「dsh-im-wecom」包含两个层次的能力：**接入能力**（来自上游 `@xmanrui/dsh-im` 插件）与**增强能力**（本仓库开发的千问侧栏读图代理补丁）。以下逐一说明每个功能的原理、配置与适用场景。

---

## 1. 企业微信智能机器人接入（上游插件能力）

| 项 | 说明 |
|---|---|
| **功能** | 把企微「智能机器人」接到本机 DSH，企微里发消息即触发 DSH 智能体执行任务 |
| **原理** | 官方 SDK `@wecom/aibot-node-sdk` 建立 WebSocket 长连接（botid + secret 认证）；消息经 `wecom-bridge.mjs` 注入 Harness 会话，回复走原生流式通道 |
| **配置** | ① 扫码创建智能机器人；② 手动绑定 Bot ID + Secret |
| **适用** | 想让同事/群成员直接通过企业微信调用本机 DSH 能力（工作区文件操作、跑 skill、问答） |

## 2. 官方 WebSocket 长连接（无需公网）

- **功能**：机器人主动外连企微长连接服务器，本机无需公网 IP、端口映射、HTTPS Webhook。
- **原理**：`WSClient({ botId, secret })` 维持连接，断线自动重连（最多 10 次），认证失败/WSAuthFailureError 进入 failed 状态并自动重试。
- **验证**：`/status`；Host 有一条到企微服务器的 Established 443 连接。

## 3. 原生流式回复与"正在思考"

- **功能**：企微端显示"正在思考中"→ 工具执行进度 → 逐步生成的回答。
- **原理**：插件订阅 Harness 会话事件，`replyStream` 推送流式预览，结束时落定最终 markdown。
- **配置**：无需配置，自动生效。

## 4. 图片 / 文件收发

- **图片入站**：JPEG/PNG/WebP 及图片形式 GIF；单张 ≤5MB，单条 ≤20MB，最多 4 张预取。企微图片 URL 带 `aeskey` 加密，插件用 `downloadFile(url, aeskey)` 解密下载。
- **文件回传**：Harness 生成的文件作为企微原生附件回传（需应用具备素材上传与文件消息能力，否则明确提示权限错误）。
- **适用**：截图提问、报告文件下发。

## 5. 🧠 千问侧栏读图代理（本仓库核心增强）

| 项 | 说明 |
|---|---|
| **功能** | 企微发图后，图片不再交给模型（纯文本模型会被拒），而是转交夸克浏览器内置千问（qwen-vl）分析，模型只收到分析文本 |
| **为什么** | DSH 模型能力预检：图片以 image block 进会话时，若模型 `inputModalities` 不含 image（如 deepseek-v4-flash），Host 直接拒绝（INPUT_INVALID / "当前模型不支持图片"）。补丁让图片**根本不进模型请求** |
| **原理** | `wecom-qwen-proxy.mjs`：下载图片 → 临时文件 → 调 `qwen-vision.js`（CDP 控制夸克千问对话页：粘贴图片 + 提问）→ 轮询回复 → 返回 `[{type:'text', text:'[千问侧栏视觉分析 N]…'}]` 纯文本 blocks → Harness 模型正常处理 |
| **关键设计** | 图片字节只存在于「企微插件 ↔ 夸克千问侧栏」之间，模型视角是"一段图片分析文字"——等价于收到链接/描述而非图片。千问页面为共享单例，代理用全局串行队列防并发打架 |
| **配置** | 见 README「千问侧栏读图代理」；环境变量 `DSH_WECOM_QWEN_VISION=0` 关闭、`DSH_WECOM_QWEN_VISION_SCRIPT` 换脚本路径、`DSH_WECOM_QWEN_TMP` 换临时目录 |
| **回退** | 代理失败（夸克未开/千问超时/脚本异常）自动回退原插件逻辑（此时纯文本模型会报"不支持图片"，属于异常路径，提示用户检查侧栏） |
| **适用** | 默认模型无视觉能力、不想为此切视觉模型（省 API 额度）、已有夸克千问侧栏工作流（零 API Key、零本地算力） |

### 代理的消息流（多图）

- 用户文字（如有）作为提问内容，同时保留在 content 里
- 每张图一个 `[千问侧栏视觉分析 N]` 文本块
- 模型综合用户问题 + 千问分析组织最终回复

## 6. 会话 / 工作区 / 模型 / Preset 控制（/命令）

| 命令 | 功能说明 |
|---|---|
| `/new` | 解除当前聊天会话绑定，下一条消息开新 Harness 会话 |
| `/sessionlist` `/session <ID>` `/history [N]` | 跨机器人管理会话：列表 / 绑定 / 看最近历史 |
| `/workspace <绝对路径>` `/workspacelist` | 切换/列出 Harness 工作区（机器人级） |
| `/models` `/model <序号或ID> [推理等级]` | 列出全部可用模型、切换当前会话模型（切换会存为默认） |
| `/reasoninglist` `/reasoning <序号或等级ID>` | 查看/切换推理等级 |
| `/presetlist` `/preset <序号或ID>` | 查看/设置机器人 Agent Preset（影响新会话） |
| `/stop` `/steer <指令>` | 停止当前任务 / 追加指令纠偏 |
| `/batch` `/send` `/cancel` | 私聊批量收集 ≤10 条文字一次提交 |
| 远程审批 | 回复 `批准`/`拒绝`/`同意`/`yes`/`no` 处理 Harness 审批 |

## 7. 多机器人独立管理

- 同一渠道可接入多个机器人，凭据、连接状态、工作区、Agent Preset、会话映射彼此独立。
- 机器人卡片支持独立「检查连接 / 重试 / 移除」。

## 8. 安全与脱敏

- Bot Secret / Token 只写入 DSH 受保护凭据存储（`$DSH_HOME/.credentials.yaml`，0600），配置文件仅存 `secretRef` 引用。
- 插件 RPC 层 `FORBIDDEN_PUBLIC_KEYS` 显式过滤 secret / secretRef / scode 等字段，任何响应不回传凭据。
- 本仓库代码不含任何真实凭据（占位符示例），发布前已做脱敏扫描。

## 设计取舍

| 问题 | 回答 |
|---|---|
| 为什么不直接用视觉模型（如 Qwen3-VL）？ | 可以，但用户场景强调"系统优势 = 千问侧栏读图"：零 API Key、零本地算力、复用夸克登录态；且文本模型保持纯文本可避免额度/网络依赖 |
| 为什么不改模型元数据"假装支持图片"？ | 假能力会让图片进模型请求、最终在 API 层报错，是死路 |
| 补丁为什么不打在 node_modules？ | 打在**源码副本**再 `link:` 安装（Junction），patch 不随插件升级丢失；`apply-patch.ps1` 可随时重打 |
