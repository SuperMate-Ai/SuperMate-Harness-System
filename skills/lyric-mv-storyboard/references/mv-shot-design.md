# 场景、镜头、转场与多镜头拼接（mv-shot-design.md）

## 一、场景设计

- 基于本句**核心意象**生成场景：路灯→城市夜街；长亭古道→郊野古亭；烛光→老屋；
  意象抽象时用**视觉隐喻**（"风带走谎话"→ 风卷起落叶/纸条/纱帘）。
- **场景复用与升级**：同一意象跨句复用场景；副歌或情绪升级时做同景异态
  （同场景不同光线/时段/天气/机位），不另起炉灶；
- 场景数量控制：一首 3-4 分钟的歌 6-10 个主场景足够，不逐句换景；
- 主色调跟随 globalMood 设渐变曲线（如：失落遗憾 = 冷蓝灰 → 深青 → 暖黄尾声）；
  每段标注光影（逆光剪影/侧窗光/霓虹/烛光/月光）。

## 二、镜头与运镜

- 每镜**一个主运镜**，写"类型+幅度+速度"并说明叙事理由：
  `The camera pushes in with small amplitude at slow speed toward her hands`；
- 运镜库：推（揭秘/逼近）/ 拉（抽离/孤单）/ 摇（交代空间）/ 环绕（沉浸/眩晕）/
  固定机位（压抑/凝视）/ 跟拍（同行/追逐）/ 缓慢横移（时间流逝）；
- 景别与情绪：大远景=孤独渺小 → 全景=关系 → 中景=动作 → 近景=交流 → 特写=情绪 → 大特写=窒息；
- 竖屏（9:16）优先保证主体与脸可见，关键信息避开底部约 1/5 播放界面叠加区；
- 主唱口型与歌词同步时，镜头不剧烈运动（口型是承重信息时用固定或微推）。

## 三、转场

| 转场 | 用在哪 |
|---|---|
| 硬切 | 节拍点、鼓点、情绪骤变；MV 默认主力 |
| 淡入淡出 | 前奏/尾奏、段落大呼吸、回忆段落 |
| 虚焦转场 | 情绪转换、回忆/幻觉进入 |
| 运动衔接转场 | 同方向甩镜/遮挡/动作匹配，跨场景延续 |

禁止无逻辑突兀跳转；相邻镜头要有转场理由（情绪/节拍/空间关系）。

## 四、多镜头拼接（总时长 > 15s 自动启用）

单段生成上限内按以下协议切段：

1. **全局美术锚点头**：每段提示词携带同一美术头
   （风格/颗粒/主色调/LUT 方向/光向/画幅），压低批次色差；
2. **切点对齐**：切点落在 1/4 或 1/8 拍、鼓点、或歌词气口上；不在元音中间硬切；
3. **头尾帧衔接**：同场景延续 → 上一段尾帧作下一段 I2VA/FL2VA 首帧续拍；
   硬切换场 → 保持同角色卡/服装/光语言，用运动方向一致性过渡；
4. **全局音轨**：全片绑定同一 Master Audio（原曲）；剪辑对齐时间轴后硬切拼接
   （ffmpeg：trim + concat + 统一 LUT/颗粒滤镜 + 音频对齐）；
5. 段间表演节拍连续：上一段"消退"状态 = 下一段"启动"状态。

## 五、器乐间奏处理

- 歌词栏写【器乐间奏】；镜头侧重流动（横移/环绕/拉远），
- 人物静默表演承接上一段情绪（延续上一句的消退态，或一个慢动作细节：
  伞柄转动/纸片落地/闭眼/抬头望向光源）；
- 间奏是情绪沉淀段，禁止新信息堆砌与突兀转场。

## 六、交付前自查

- [ ] 每句有一个主导表演节拍，且跟随情绪曲线？
- [ ] 每镜一个主运镜且有叙事理由？
- [ ] 相邻镜头转场有理由，无突兀跳转？
- [ ] 副歌重复遍视觉已变化？
- [ ] 间奏段歌词栏写【器乐间奏】且侧重镜头流动？
- [ ] >15s 时已按拼接协议切段并带全局美术锚点？
- [ ] 人物外貌遵守角色锚点（防变脸）？
