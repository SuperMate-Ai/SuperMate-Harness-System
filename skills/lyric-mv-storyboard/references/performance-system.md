# 三层表演体系（performance-system.md）

三层：**行动逻辑 → 表演节拍 → 面部动作时序**。每句歌词只取一个主导表演节拍，
跟随歌词情绪流动，禁止全程同一个表情。

## 第一层 · 行动逻辑

回答三个问题（角色此刻的戏剧状态）：

| 问题 | 写法要求 |
|---|---|
| 目标 | 这一句里角色**此刻想要什么**（具体：等一个回答/挽回/释怀/告别） |
| 阻碍 | 什么挡着（对方已走远/说不出口/时间已过） |
| 策略 | 怎么应对（站在原地/握紧伞柄/移开视线/终于抬头） |

行动逻辑落为**可见行为**，不写抽象心理词：`像是听见了什么`、`神色一凛` 这类不可见内部状态
禁止入提示词——改写为正在发生的替代动作（呼吸变化、视线落点、手部停留）。

## 第二层 · 表演节拍

词表（每句只选一个）：

| 节拍 | 含义 | 可见落点示例 |
|---|---|---|
| 平静 | 情绪被压平，无波动 | 呼吸均匀，视线平直，手静止 |
| 掩饰 | 假装没事 | 嘴角维持弧度，目光快速避开，整理衣角 |
| 失衡 | 被击中，失控前兆 | 肩线一沉，脚步顿住，呼吸断一拍 |
| 抑制 | 强压情绪 | 喉结滚动，抿唇，手指蜷进掌心 |
| 释放 | 情绪涌出 | 眼泪滑落，肩膀松塌，深呼一口气 |
| 恍惚 | 失神出神 | 视线失焦，动作慢半拍，像在回忆 |
| 决绝 | 做出决定 | 抬眼直视，转身，放下手中物 |

副词换成节奏与行为：`愤怒地说` → `先压低音量、吞回半句话、最后直呼对方全名`（须符合歌词情绪）。

## 第三层 · 面部动作时序

每句写三拍：**启动 → 峰值 → 消退**

```text
启动：触发信号（听见什么/看到什么/内心决定），表情从哪里开始变化
峰值：到达情绪最高点（微表情/呼吸/视线落点/一滴泪/一次眨眼）
消退：如何逐步回落（回到平静/转开视线/闭眼/苦笑收尾）
```

示例（"你已经走向远方"）：

```text
启动：目光追着对方背影，眉间微蹙，下颌收紧
峰值：眼睫低垂，喉结滚动一下，呼吸停半拍
消退：缓缓移开视线，肩膀极轻地塌下去，嘴角平直
```

## 表演弧（长句/副歌连续表演）

单句写三拍；连续两句以上组织成**表演弧**：触发 → 接收 → 处理 → 决定 → 结果。
- 触发：外部声音/动作/歌词事件（来源可追溯）；
- 接收：注意被什么抓住；
- 处理：一两个细微信号，不是面部部件清单；
- 决定：角色采取或抑制什么行动；
- 结果：到达本段终点的情绪与身体状态（且是下一镜可信起点）。

## 表演节拍跟随情绪曲线

- 全曲情绪曲线：前奏平静 → 主歌压抑 → 预副歌失衡 → 副歌释放 → 桥段恍惚 → 尾声平静/决绝；
- 每段只允许在其区间内的节拍滑动，副歌是全曲表演峰值；
- 同一句重复两遍时第二遍节拍必须升级（掩饰 → 失衡），不原样重放。
