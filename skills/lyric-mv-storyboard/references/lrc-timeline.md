# 时间轴规则（lrc-timeline.md）

## 一、LRC 时间轴解析（有 .lrc 时）

LRC 标准格式示例：

```lrc
[ti:送别]
[ar:李叔同]
[00:08.50]长亭外
[00:12.00]古道边
[00:15.50]芳草碧连天
[00:22.00]晚风拂柳笛声残
[00:28.50]夕阳山外山
```

解析规则：

1. **元信息行**（`[ti:]` `[ar:]` `[al:]` `[by:]`）不参与时间轴，只记录歌名/歌手。
2. **时间标签**：`[mm:ss.xx]` 或 `[mm:ss]`；支持**一行多标签**（重复句）
   `[00:12.00][00:40.00]副歌重复句` ——每个标签都生成一行记录。
3. 按时间升序排序，生成逐句时间轴；每句的**开始时间**=标签时间，**结束时间**=下一句开始时间。
4. **器乐间奏识别**：相邻歌词行间隔 > 2.5s 的空白区间标记为间奏段
   （`[start-end] 器乐间奏`），分镜里歌词栏写【器乐间奏】。
5. 时间戳与歌曲实际不符（如歌手版/伴奏版不同）时，以用户确认为准，标注"未验证"。

## 二、BPM 估算（无 LRC 时）

1. **拍长** = 60 ÷ BPM（秒/拍）。BPM 85 → 0.706s/拍。
2. **单句时长估算**：
   - 抒情/民谣：每字 0.35–0.45s；国风/慢歌取上限，流行取中值；
   - 说唱/快歌：每字 0.25–0.35s；
   - 句间停顿：0.5–1 拍；段（主歌/副歌）间呼吸：1–2 拍。
3. 例：BPM 78、一句 8 字抒情 → 8×0.40 ≈ 3.2s + 停顿 0.5 拍(0.38s) ≈ 3.6s。
4. **估算永远标注为估算**；进入生成前如用户有真实音轨，用音轨长度校准总时长。

## 三、切分点规则（两种时间轴通用）

- 切分点必须落在**语义停顿**（逗号/句号/换气）或**节拍**（1/4、1/8 拍）上；
  禁止在词中间或元音中段硬切。
- 歌词行是分镜的最小单位；长句可拆半句（在逗号处），短句可并句（同一场景同一情绪）。
- 副歌重复时视觉必须变化（不同场景/机位/光态/景别），不原样复用上一遍分镜。
- 整曲时间轴头部留 2–3s 前奏（黑场淡入或环境建立镜头），尾部留 2–4s 尾奏收束。
