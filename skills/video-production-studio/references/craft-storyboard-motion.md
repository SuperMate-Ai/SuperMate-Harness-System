# 分镜、关键帧与视频提示词手艺（craft-storyboard-motion.md）

## 一、分镜与冻结关键帧（分镜.md）

### 镜头职责

每镜有**唯一职责**、明确来源、可见起止状态和合理时长；切镜必须带来信息/权力/情绪/空间/节奏变化；
同义重复镜头删掉；同一动作不跨镜重复发生；终点应能成为下一镜可信起点。

### 空间与连续性

- 复杂群戏先锁空间锚点和屏幕方向，再决定景别变化；
- 锁定人物朝向、位置、视线、持物、出入口、屏幕方向；
- 竖屏构图优先保证主体和反应可见；关键信息的可读性优先于装饰性运镜。

### 冻结关键帧（只投影起点）

- 只写该瞬间能看见的内容：构图/主体/场景/光线/禁止项；
- 删除终点才出现的文字、动作、姿态或道具状态；文字、手指、反射、遮挡要可生成。

### 景别与情绪（参考）

大远景=疏离敬畏 → 远景=交代 → 全景=关系 → 中景=动作 → 近景=交流 → 特写=情绪 → 大特写=窒息脆弱。

### 运镜与叙事（参考）

推近=揭秘 / 拉远=抽离 / 横移=同行 / 升降=命运 / POV=代入 / 固定=压抑。
高适配度技法（按需使用）：荷兰角/逆光剪影/遮挡切入/OTS/POV/跳切/J-L 切/动作顺接/定格/慢动作/
音画对立/隐藏动作/悬念公式/闪回锚点/限制空间。

## 二、视频提示词内容纪律（喂给 H3 之前的内容设计）

### 每镜一条主线

**静态锚点 → 起点 → 触发 → 主体动作 → 次级反应 → 运镜 → 声音 → 可验证终点**

- 从可见起点开始，以可验证终点结束；
- 主体、动作对象、方向、幅度、速度和先后关系明确；
- 表演写动作与反应，不写无法执行的抽象结果（❌"展现内心矛盾" → ✅"用背对背构图展现疏离"）；
- 运镜与人物动作不争夺注意力；复杂运镜必须有叙事理由；
- 声音只写该镜需要的对白、画外音、环境或转场职责，不擅自补歌词；
- 不跨下一镜、不要求互斥动作、不让人物或道具瞬移变形。

### 可生成性检查

- **判据只有一句：这个动作在普通生活影像里是否大量出现**。写完后念给没读过剧本的人，
  他能不能马上比划出来；需要先解释一遍才能比划的，生成模型多半也做不出来。
- 放心写：走进来、坐下、站起来、回头、点头、递东西、接过、抱住、推开门、放桌上、翻页、伸手去够。
- **四类高风险写法**：
  1. **精确拦截**：两人同时争夺小物、用手挡住正在合上的东西、运动中截住某物——时序与位置要同时精确，最容易整镜崩掉；
  2. **不可见的内部状态**：`像是听见了什么`、`神色一凛`、`忽然明白过来`——推断不是画面；
  3. **否定式动作**：`没有接话`、`没有按下去`——画面里"没发生的事"无法生成，改写成一个**正在发生**的替代动作；
  4. **精细编排链**：一拍串起三步以上手部动作（尤其左右手分工），四秒四步物理上也不成立。
- 戏剧信息来自**常见动作的组合与时机**，不来自动作本身的精巧：
  高风险 `他用手掌挡住正在合上的笔记本边缘` → 可生成 `他把笔记本合上，手放在盖子上没有移开`。
- **改写五法**（按顺序试，取第一个成立的）：
  1. 换承担者：让物件/环境承担变化（`门被风带上` 好过 `他用脚勾住门`）；
  2. 拆到相邻镜：把精细动作拆成"动作前"与"结果"两镜（`笔停在纸上` + `纸上多了一行字`）；
  3. 换成停留：`做完之后手没有拿开`（停留最容易生成）；
  4. 交给声音：动作不可见时用已声明的声源承担；
  5. 确实不可替代时标注该镜高风险并给出可接受降级实现。
- 改写不得改变已接受的镜头边界、起止状态与剧本事实；唯一可行的改写会改变戏剧结果时，
  路由回剧本/分镜 owner 修订，不在提示词里硬写。
- 首镜运动起点：RH I2V 必须显式声明第 0 帧即运动（`第0帧起画面即处于运动中，禁止静态开场`）。

### 表演过程（performance arc）

表演不是表情标签序列（`震惊—生气—悲伤`）。找最小变化五步：
**触发**（外部声音/动作/台词或内部决定，来源可追溯）→ **接收**（注意被什么抓住）→
**处理**（一两个细微信号，不是面部部件清单）→ **决定**（采取/抑制什么行动）→
**结果**（到达已确认终点的情绪与身体状态）。
把副词换成节奏和行为：`愤怒地说` → `先压低音量、吞回半句话、最后直呼对方全名`（须符合台词与人物）。
不能发明新信息、关系转变或角色意图。

### 时间与长度

- 默认把几秒写成一条读得出先后的节拍链：`首先<起手状态>；接着<动作、方向与幅度>；
  随后<结果>；与此同时<并行通道>；最终<结束状态>`。并行通道用「与此同时」显式标出，一条链只给一条，
  同一只手/同一道视线不能同时走两条。
- **至少写一处量级**（约五厘米/约三十度/约一掌）：幅度由你写是本镜要拍成什么样；
  写不出量级通常说明这一拍还没想清楚。
- 可以钉一到两个锚点秒数（起手不动约半秒、终点定住约一秒）；显式分段（按秒）只有制作需要时才写，
  且非重叠段长相加必须**等于**镜头时长——超出会被截断（段尾动作/台词/终点丢失），
  不足更糟（剩余秒数会被执行端用未批准的动作填满）。
- 写短：这是给生成器的执行指令不是散文，**两百字上下**能写满，超三百字基本有冗余；
  省字是合并不是删项——最先不能掉的是台词挂载与声音。

### 参考图语义

- 有真实参考帧时，静态外观（身份/造型/地点/构图）由参考帧与视觉设定共同拥有；
- 图生视频原样携带 `REF-*` 槽位、顺序、路径、中文名、「控制」/「不得控制」范围；
- 文生视频必须写非空「静态视觉锚点」并把必要事实纳入正文，不得只写 `preserve 保持已有外观`。

## 三、H3 原生正文写法（融合 h3-prompt-writing）

### 模式选择

| 参考情况 | 模式 | 首行指令 |
|---|---|---|
| 无参考图 | T2VA | 无，直接三核心字段 |
| 单张首帧 | I2VA | `For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.` |
| 首尾帧 | FL2VA | `How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark ...; Picture 2 (from Shot N) aligns with the S.SS-second mark ...` |
| 末帧 | L2VA | `How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the S.SS-second mark of the target video.` |
| 多参考 | Ref2VA | 六段式（见主 SKILL.md） |

### 三核心字段写法

- **integrated_multimodal_description**：`[Shot 1]` 开头写风格与初始构图（Cinematic/live-action/2D-animated/3D CG/watercolor...）；
  后续镜头 `[Shot 2] At 00:03.500, the camera cuts to ...`；第一镜不加时间戳。
- **overall_soundscape**：1-4 句英文一段，汇总环境音/物理动作声/非语言人声；对白与演唱不重复进来；
  只有明确要求全片静音才写 `N/A`。
- **non_diegetic_music**：1-3 句，写配器/速度/节奏/动态；不用抽象情绪词；无配乐写 `N/A`。

### 说话者与对白

- 说话者稳定 ID `(S1)`/`(S2)`，多人同时 `(S1,S2)`；不出声的角色不编号；
- 对白/歌词 `说话者描述 (S1) says: <d>[语言] 原文</d>`，逐字保留不翻译；
- 画外音用 `says in an off-screen voiceover`，紧跟注明 `while his lips remain completely closed`；
- 台词跨切点用 `<scenetrans>` 并说明声音跨切连续；被片尾截断用 `<cutoff>`；
- 画面可见文字（招牌/字幕/霓虹）用英文双引号保留原文。

### 运镜表达

运镜=类型+幅度+速度，写成自然英文动作，不要堆标签：
`The camera pushes in with small amplitude at slow speed toward the folded letter in her hands.`

### Ref2VA 六段式要点

1. `subject_definitions`：`<Subject N>` 可复用内容 / `<Picture N>` 帧锚点 / `<Video N>` 结构源 / `<Audio N>` 音频；
   一个内容一个标签，来源资产同名时注明出处；
2. `summary`：以 `[task type]` 前缀开头（reference generation / keyframe completion / video continuation + ...），一句话；
3. `retention_analysis`：逐标签一行，标记 `fully_preserved / partially_preserved / attribute_transfer / weak_reference`（音频用 `fully_copy / partially_copy / reference / weak_reference`）；
4. `detailed_description`：风格开场句（一至两句）→ `[Shot 1]`...；生成任务 350-500 英文词，对白密集时优先装下完整对白时间线；
5-6. `overall_soundscape` / `non_diegetic_music` 同基础模式，引用 `<Audio N>` 时在对应层说明 copy/reference 关系。

## 四、配乐/时间线音乐（用户要求时）

视频提示词文档增加独立章节：使用区间、剧情功能、进入/退出、动态曲线、禁用项。
歌词只能来自用户提供或明确接受的文本；主题曲用已确认歌词，纯配乐不携带歌词。
供应商不能精确承诺时长时，生成源音轨后由剪辑按文档混音意图完成落点、循环、淡入淡出与对白 ducking。
