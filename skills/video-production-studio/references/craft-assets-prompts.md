# 资产拆解与图片提示词配方（craft-assets-prompts.md）

## 一、资产拆解（视觉设定.md）

### 先区分四类

| 类别 | 定义 | 归谁 |
|---|---|---|
| 身份 | 换一个就不再是同一个人/地/物 | 视觉设定（新建或复用） |
| 变体 | 身份不变，服装/伤势/时段/天气/开合/持有状态改变 | 视觉设定（变体条目） |
| 镜头瞬态 | 姿势、视线、左右手、站位、机位 | 分镜 |
| 故事语义 | 知识、目标、关系、情绪 | 剧本/开发 |

### 工作流

1. 只读当前范围的剧本和已决定的视觉方向；
2. 逐场找实体、可见描述、状态变化和含混指代，**先不创建资产**；
3. 对每项决定：新建 / 复用 / 增加变体 / 标记未决；含混指代不猜；
4. 写最小可识别设定：识别锚点 + 本集状态 + 变化原因；
5. 检查造型/伤势、持物/所有权、道具状态、地点时段/天气/光态与跨集 outgoing。

### 内容要求

- 每项先写"什么不变使它仍是同一资产"，再写本集变化；
- 识别锚点必须可见、可生成、可比较（发型/发色/脸型/体型/服装款式颜色材质/标志物），
  不用空泛质量词（"气质清冷""很漂亮"）替代事实；
- 不复制剧情摘要，只保留下游生成、分镜或连续性真正需要的事实；
- 文字、标识和敏感信息遵守项目政策，不擅自补造品牌或私密信息；
- 声音方向（可选）：音色/语速/口音/授权边界。

## 二、图片提示词配方（图片提示词.md）

### 条目类型与用途

| 类型 | 用途 |
|---|---|
| 身份板 | 固定人物/地点/道具的可复用事实 |
| 造型/状态变体 | 同一身份的不同状态（换装/伤势/天气/开合） |
| 地点板 | 空间结构/标志物/光线 |
| 道具板 | 尺度/材质/功能/文字 |
| Production Sheet | 多对象组合板（多视图对照） |
| Lookdev 风格帧 | 比较视觉方向的代表帧 |

### 通用配方（一条正文）

**主体与身份锚点 → 当前变体 → 构图/视角 → 光色/材质 → 背景边界 → 禁止项**

- 开头先写对象和用途，不用风格词淹没身份；
- 只包含当前图能同时满足的要求；多视图/状态对照写清版面关系；
- 保留稳定识别锚点，变体只改允许变化的部分；避免无验证作用的质量词堆砌；
- 可见文字、logo、水印、界面、字幕明确允许或禁止；
- 正文可直接复制，不含占位符、流程说明、文件路径或 QA 结论。

### 参考图控制边界

每张参考图只控制身份、造型、地理、构图或风格中的**明确部分**；写清「控制」与「不得控制」范围。

### Z-Image 执行注意

- `comfyui_generate`：竖屏默认 720×1280；steps 8（turbo ≤10）；cfg 1；shift 3；lora 0.95；
  同参数同种子可复现，生成后记录 seed；
- 提示词纯文本单条，不写 JSON/Markdown 结构；
- 结果落 `剧集/<EP>/制作成果/`，作为后续分镜参考图/视频首帧的 `REF-*` 来源。

## 三、资产复用纪律（跨集/全片）

- 角色/场景设定图一旦生成，全剧复用，不重复生成；
- 改图必须基于原图（image2image），不文生图重建；
- 角色外观一旦锁定，全剧不得漂移（发型/服装/标志物逐集一致）；
- 三测试：剪影（涂黑认人）/ 溯源（删特点丢什么）/ 三距（远读剪影色块，中读形状姿态，近读五官细节）。
