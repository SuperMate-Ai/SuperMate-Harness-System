# 阶段契约与规则分级（stage-contract.md）

定义每个阶段拥有什么、继承什么、不越权什么；以及规则的分级与引用方式。

## 规则分级

- **`structural_invariant`**：本地可证明的引用、ID、显式状态矛盾（如分镜引用了不存在的
  `SHOT-*`、视频提示词与分镜时长不一致）。可直接阻断。
- **`reviewed_invariant`**：升级是否真实、承诺是否兑现、连续性是否成立等语义义务；
  由 reviewer 引用证据判断。
- **`craft_default`**：通常有帮助的做法；创作者说明理由后可覆盖。
- **`taste_option`**：钩子、弧线、视角、结局气质等选择；不得单独阻断。

不要用固定的情节点数量、转折时刻、篇幅比例或镜头数配方替代因果判断。

## 阶段所有权

| 阶段 | 拥有 | 不越权 |
|---|---|---|
| 开发/分集 | `项目开发/creative-brief.md`、`episode-map.jsonl`、`story-engine.md`、`director-brief.md` | 不写场景动作与台词 |
| 剧本 | `剧集/<EP>/剧本.md` | 不拆资产、不写提示词 |
| 资产 | `剧集/<EP>/视觉设定.md` | 不写图片提示词、不抢写剧情语义 |
| 图片提示词 | `剧集/<EP>/图片提示词.md` | 不生成媒体 |
| 分镜 | `剧集/<EP>/分镜.md` | 不写视频提示词正文 |
| 视频提示词 | `剧集/<EP>/视频提示词.md` | 不生成媒体、不创作歌词 |
| 生产 | `剧集/<EP>/制作成果/`（+ 临时 job 与运行记录） | 不创作提示词；绝不把"继续"当确认 |
| 审查 | `审查/<EP>-审查.md` | 不代替 owner 修改来源文件 |

五份文档齐备后可对跨文档结构做一次机械核对；内容质量由创作者/审查判定。

## 关键 ID 与引用契约

- `SHOT-*`：分镜镜头条目，稳定 ID；拆镜、并镜或改变职责时保留未受影响的 ID，并说明哪些
  下游视频提示词需要刷新（但不自动重写用户没点名的文件）。
- `IMG-*`：图片提示词条目 ID。**不代表图片已生成/已提供/可用**；只用于查找。
- `MOTION-*`：视频提示词条目 ID，引用对应 `SHOT-*`。
- `REF-*`：创作者已提供的真实图片槽位。与 `IMG-*` 是两条独立轴：有合法图片提示词项时
  输入参考图仍可为「无」；有真实参考图时图片提示词项也可为「无」。
- 实际进入生产时，以 job 的 `references`（实际文件字节）为准，不是文档里的路径描述。

## 输出语言

- 创作者可读说明跟随用户语言。
- 可复制提示词正文：图片提示词跟随项目约定（缺省中文）；**视频提示词正文固定 H3 英文格式**，
  对白/歌词/画面可见文字保留原语言。不能从说明语言推断提示词语言。

## 生产边界（复述核心）

外部生产永远 `preview -> explicit confirm -> run`，四步不可合并；job/prompt/参数/输出/直接输入
任一变化，旧确认立即失效；失败重试需要新的明确确认。供应商凭据只在运行环境读取，不进项目文件。
