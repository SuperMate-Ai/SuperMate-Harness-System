# 审查 Rubric（review-rubric.md）

用户点名审查时才做。优先由未参与当前版本创作的 reviewer 执行；条件不允许时自检并如实说明。
审查与修改是两个工作单元：只定位问题、影响和必须达到的修订结果，不在同一轮替 owner 改来源。

## 审查范围

`story_script` / `assets_continuity` / `image_prompts` / `storyboard_keyframes` /
`video_prompts` / `production_outputs` / `full_episode` / `delivery_privacy` / `project_calibration`。
只读对应资料，不预加载整个项目。

## 审查文件结构

```markdown
# EP001 审查

- 范围：剧本、分镜、视频提示词
- 结论：REVISE
- 复核方式：独立 reviewer / 自检

## Blocker · REV-001 · 画面文字未被镜头承载
- 位置：剧本.md / EP001-SC002；分镜.md / SHOT-EP001-004
- 证据：……（文件名/标题 ID/行号/短引文）
- 影响：……
- 修订结果：由分镜补入准确文字及可读条件。
- 严重程度：blocker ｜ 规则：reviewed_invariant
```

不建立 sources 声明、哈希、record ID 或第二套状态；引用只使用文件名、标题 ID、行号或短引文。

## 工作流

1. **冻结范围**：写清要审哪些文件/章节/镜头/提示词及创作者已明确的限制；目标中途变化重新读取。
2. **先查可证明事实**：
   - 五文档的可见 ID（SHOT-/IMG-/MOTION-/REF-）和时长是否一致；
   - 剧本对白/动作/声音/画面文字是否都有画面或声音承载；
   - 人物、地点、道具状态和镜头起止是否连续；
   - 视频提示词是否从准确起点到准确终点、是否跨镜、是否有互斥动作；
   - 私有输入、凭据、绝对路径或内部流程文字是否泄漏。
3. **带证据审内容**：每个 finding 含位置、必要短引文或冲突事实、观众/制作影响、必须达到的
   修订结果、owner、严重程度。不能只说"AI 味""不够电影感"或给无证据分数。
4. **跨文档综合**：剧本事实 → 视觉设定 → 镜头职责与边界 → 冻结关键帧 → 视频运动 → 下一状态。
   优先守住原意、知情时机与连续性，不奖励脱离来源的华丽提示词。
5. **结论与分派**：按 owner 分组修订要求；本轮完成后交还控制权，修改和复审只有用户明确请求时开始。

## 结论分级

- `APPROVE`：没有阻断问题；
- `APPROVE_WITH_NOTES`：只有不阻断的改进；
- `REVISE`：存在结构、内容或限制冲突；
- `PROVISIONAL`：关键输入不足，暂时无法完成判断。

## 严重程度

- `blocker`：不安全、不可交付或会让流程走错；
- `major`：明显破坏剧情理解、连续性或制作结果；
- `minor`：有具体影响但不阻断；
- `note`：创作选择或可选润色。

## 各范围重点

| 范围 | 重点检查 |
|---|---|
| story_script | 三门槛（完整/自洽/可追随）、承诺兑现、情绪曲线、对白是否在争取/回避/试探、无模板感 |
| assets_continuity | 身份 vs 变体判断、识别锚点可生成、跨场/跨集状态、含混指代是否标注未决 |
| image_prompts | 配方六段齐全、参考控制边界明确、正文可复制无占位符、文字政策 |
| storyboard_keyframes | 原文镜头承载、每镜唯一职责、冻结关键帧只投影起点、空间/持物/视线连续 |
| video_prompts | H3 格式正确（模式/标签/字段）、起点→终点可验证、不跨镜、可生成性（形变/互斥/瞬移） |
| production_outputs | 输出与已确认 job 一致、无重复内容、失败重试是否重新确认 |
| delivery_privacy | 私有输入/凭据/绝对路径/隐藏运行状态是否被带出边界 |

## 边界

- 不提交图片/视频/TTS/音乐任务，不配置通道，不把预览当生产授权；
- 无法读取媒体时明确限制，不从文字或通道状态推断脸部一致、表演、口型、混音或市场表现；
- 生产观察必须绑定准确输入、提示词、参考、配置和结果版本，不泛化成通用规则；
- 审查文件只保留修订所需的最小证据，不复制完整私有输入。
