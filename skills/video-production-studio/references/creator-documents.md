# 五份创作文档格式规范（creator-documents.md）

每集按需维护五份 Markdown，以它们作为创作事实。**不预建空文件**，一次请求只创建需要的文档；
场次/资产组/镜头组是内部批次，自动续跑，不落盘 JSON/JSONL、索引、指纹、覆盖表、QA 或审核表。

```text
项目/
├── 输入/                      # 创作者原始材料（只读）
├── 项目开发/                  # 可选：creative-brief.md、episode-map.jsonl、story-engine.md
├── 剧集/
│   └── EP001/
│       ├── 剧本.md
│       ├── 视觉设定.md
│       ├── 分镜.md
│       ├── 图片提示词.md
│       ├── 视频提示词.md
│       └── 制作成果/          # 已确认生产产出的图片/视频/音频
├── 审查/                      # 可选：EP001-审查.md
└── 导出/                      # 交付包
```

## 1. `剧本.md`

```markdown
# EP001 · 集名

## EP001-SC001 内 · 地点 · 时间/天气

动作叙述（第三人称，可拍摄）。

[VO] 角色：画外音台词。

角色（表演提示）：对白。

[画面文字] 屏幕上可见的文字内容（如实抄写）

[SFX] 声音效果说明

[转场] 转场说明

[连续性] 需要下游保持的状态交接（只写前文动作已建立、又容易丢失的状态）
```

- 场景标题格式固定：`## EP001-SC001 内/外 · 地点 · 日/夜/黄昏(可选天气)`。
- 对白含冒号的表演提示要写在括号里，不要把"动作叙述：xxx"误写成对白。
- `[VO]` 画外音 / `[OS]` 画外（场景内但画面外）/ `[SFX]` / `[画面文字]` / `[连续性]` / `[转场]`。

## 2. `视觉设定.md`

按对象类型分节，每项最小可识别结构：

```markdown
## 人物 · 江晨
- 身份（不变）：26 岁东亚男性，清瘦长脸、高眉骨、深眼窝、短寸黑发、橄榄绿军装
- 本集状态/变体：常服无帽；第 3 场后领口松开
- 变化原因：……
- 声音方向（可选）：年轻、语速快、带克制感

## 地点 · 文工团办公室
- 不变：旧木办公桌、玻璃台面、蓝灰文件柜、左侧窗光、搪瓷茶缸
- 本集光态/时段：日

## 道具 · 搪瓷茶缸
- 不变：白色搪瓷、缺口、旧茶渍圈
- 状态：装满冷茶
```

原则：先写"什么不变使它仍是同一资产"，再写本集变化；识别锚点可见、可生成、可比较；
服装/伤势/湿污/开合/光态通常是变体不是新身份；多集状态写生效与持续范围。

## 3. `图片提示词.md`

```markdown
## IMG-EP001-001 · 江晨角色板
- 用途：身份板（角色参考）
- 控制：发型/脸型/服装/气质；不得控制：场景与表情
- ### 可复制提示词
> （正文：主体与身份锚点 → 当前变体 → 构图/视角 → 光色/材质 → 背景边界 → 禁止项）
```

- `IMG-*` 是稳定条目 ID，不声明图片已生成；实际图片只能来自创作者输入或已确认生产结果。
- 正文直接可复制，无占位符/文件路径/QA 结论；可见文字明确允许或禁止。
- 常见条目类型：身份板、造型/状态变体、地点板、道具板、组合 production sheet、Lookdev 风格帧。

## 4. `分镜.md`

```markdown
## SHOT-EP001-001 · 年轻的手
- 来源：EP001-SC001
- 时长：5s ｜ 景别/机位：特写 · 固定机位
- 起点：右手放松摊在玻璃桌面
- 终点：材料纸角碰到指尖
- 声音：办公室环境音
- 图片提示词项：无 ｜ 输入参考图：无
- 空间锚点：玻璃桌面中央偏右，左窗光，浅景深
### 冻结关键帧提示词
> （只写该瞬间可见内容：构图/主体/场景/光线/禁止项；不写终点才出现的动作与状态）
```

- 每镜写唯一职责、来源、时长、景别/机位、起点、终点、声音和视觉依据；锁定朝向/位置/视线/持物/出入口。
- 冻结关键帧只投影镜头起点；删除终点才出现的文字、动作、姿态或道具状态。
- 参考图槽位 `REF-*`：显式顺序 + 仅用 `/` 分隔的项目相对路径 + 中文名 + 「控制」/「不得控制」范围。

## 5. `视频提示词.md`

```markdown
## MOTION-EP001-001 · 年轻的手
- 分镜：SHOT-EP001-001
- 时长：5s
- 生成方式：文生视频（无参考图）｜ 图生视频（有 REF-* 参考图）
- 输入参考图：无 ｜ （或：REF-001 路径/中文名/控制范围）
- 静态视觉锚点：（文生视频必填；图生视频可省略重复外观）
- 起始帧：…… ｜ 终点：……
- H3 模式：T2VA / I2VA / FL2VA / L2VA / Ref2VA
### 可复制提示词
> （整段 H3 原生提示词，可直接粘贴执行）
```

- 每镜从已确认起点到可验证终点的变化：触发、主体动作、次级反应、运镜、声音。
- **文生视频必须写非空「静态视觉锚点」**并把必要事实纳入正文；不得只写 `preserve/keep 保持已有外观`。
- 图生视频原样携带分镜的 `REF-*` 槽位、顺序、路径、中文名与控制范围；静态身份/造型/地点由参考帧与视觉设定共同拥有。
- H3 正文规范见主 SKILL.md 第 ⑤ 节；复杂 Ref2VA 写前读 `h3-prompt-writing/references/ref-en.txt`。

## 跨文档一致性检查（五文档齐备后）

剧本事实 → 视觉设定 → 镜头职责与边界 → 冻结关键帧 → 视频运动 → 下一状态；
可见 ID（SHOT-/IMG-/MOTION-/REF-）与时长互相引用一致；不把流程说明/QA 结论写进可复制正文。
