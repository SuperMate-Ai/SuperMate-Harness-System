# deepseek-eyes
[![DSH Plugin](https://img.shields.io/badge/topic-dsh--plugin-2ea44f)](https://github.com/topics/dsh-plugin)

**DeepSeek Harness（DSH）技能：协助文本 AI 模型做图片分析（给文本模型长眼睛）。**

在 DeepSeek Harness 里给 DeepSeek（或任意文本模型）装上一双"眼睛"——图片 → 视觉模型转文字 → 文本模型"看见"。
