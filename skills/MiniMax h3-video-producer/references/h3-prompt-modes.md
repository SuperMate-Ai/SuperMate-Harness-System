# H3 三模式提示词模板

> 按 h3-prompt-writing 规范，主体用 `integrated_multimodal_description / overall_soundscape / non_diegetic_music` 三字段；以下为可直接套用的骨架（中文台词用 `<d>[Chinese] ...</d>` 原样保留，逐字与口播稿一致）。

## 通用角色锚定段（每段开头可复用）
```
3D CG 电影级渲染，B站科技口播风格，<延续上一段>：<构图>，<背景>；人物完全继承参考图全部特征——<发型/眼睛/皮肤/服装/发光细节>，身份与前段完全一致，不漂移不换装。
人声：<人声描述，如冷静沉稳/活泼>，语速约<280>字/分钟（约<4.7>字/秒），标点不刻意停顿，仅语义节点0.2秒极短停顿；在<N>秒内完整讲完台词。人物口型、发音节奏、面部表情与中文台词精确同步，只说如下指定台词，不额外增加旁白、喊话、唱歌或无关内容：
<d>[Chinese] <台词>。</d>
全程强约束：人物五官、服装、发光细节与参考角色保持一致，不漂移、不穿模、不新增无关内容。
```

## 模式1 全屏主持人（开场/结尾）
```
构图：中景（腰部以上）居中，浅色极简书房/干净背景，画面无叠加素材、无文字水印。
动作：面向镜头，神情<沉稳/亲和>，固定机位，无大幅运镜、无跳切。
```

## 模式2 小头像主持（正文讲解软件界面/网页/截图）
```
构图：特写镜头（头部+上肩，脸部占画面主体），浅色干净背景，为左下角圆形画中画准备。
动作：第0秒视线转向画面右侧，像在侧身观看右侧的主屏图表/界面，不是直视镜头；自然眨眼、轻微点头和微小头部动作，口型与讲解同步；固定机位，无跳切。
```

## 模式3 纯画外音（图表特写/原理/数据）
```
此段不需要人物视频；仅取本段音轨（人声旁白）叠加到主画面素材上。
主画面：<图表/流程图>，合成时用缓慢推镜（zoompan）聚焦重点；画面无任何人物。
```

## 音效与音乐模板
```
overall_soundscape: 安静的环境底噪，轻微室内环境音，干净聚焦在人物声音上。
non_diegetic_music: 轻电子极简科技背景乐，音量低于人声30%，全程恒定无起伏；<纯画外音段保持恒定>。
```

## 台词校验
- 每段台词单独存 `dialogue/<块>.txt`，用脚本与提示词内 `<d>` 逐字比对（连字符变体归一化）。
